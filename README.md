# LRJ Pro Lights & Sound Concepts: Next.js funnel
1. npm install
2. npm run dev  (http://localhost:3000)
3. Edit lib/site.js for phone, prices and copy. Replace public/logo.png if needed.
4. Copy .env.example to .env.local and add LEAD_WEBHOOK_URL to receive quote requests in Discord or Slack.
5. Deploy: push to GitHub, import in vercel.com, add LEAD_WEBHOOK_URL in Environment Variables.
